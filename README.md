## Возможности

- **Ссылки WDTT Plus** — `wdtt://connect?…` из приложения и бота WDTT Plus, старые ссылки `wdtt://` и `qwdtt://`.
- **Открытие ссылок в один клик** — ссылка из Telegram или браузера сразу открывается в RWDTT.
- **Транспорт WDTT Plus** — внутри работает официальный клиент WDTT Plus, тот же, что в Android-приложении: соединение, потоки и скорость как в WDTT Plus.
- **Подключение как в WDTT Plus** — UDP с запасным TCP/TLS или только TCP/TLS для сетей, где режут UDP.
- **Устойчивость** — после сна компьютера или смены сети каналы проверяются сразу, маршруты перестраиваются под новый роутер, упавший клиент перезапускается сам.
- **Исключения из туннеля** — выбранные сайты, IP и подсети открываются напрямую, минуя VPN.
- **Обновление из приложения** — новая версия скачивается, проверяется и устанавливается одной кнопкой.
- **Работа в трее** — свёрнутое окно прячется в трей и почти не расходует ресурсы.

## Как это работает

Приложение поднимает WireGuard-интерфейс Windows и передаёт его трафик клиенту WDTT Plus. Клиент ведёт трафик через TURN/DTLS-серверы VK, оборачивая пакеты в RTP с шифрованием. Для провайдера это выглядит как обычный звонок VK.

Клиент WDTT Plus (`go_client` из [WDTT-Plus](https://github.com/Ivan4537/WDTT-Plus)) встроен в приложение и запускается отдельным процессом — так же, как в Android-приложении WDTT Plus. RWDTT отвечает за окно, туннель, маршруты, исключения и обновления.

```
Приложение → WireGuard → ChaCha20/RTP → VK TURN (UDP / TCP / TLS) → DTLS → сервер WDTT / WDTT Plus (VPS) → интернет
```

Нужен свой сервер WDTT или WDTT Plus. Установить сервер WDTT Plus можно [по инструкции из его репозитория](https://github.com/Ivan4537/WDTT-Plus).

## Установка

1. Скачайте `rwdtt-windows-amd64.exe` со страницы [последнего релиза](https://github.com/makdren/PWDTT-Plus/releases/latest).
2. Запустите его. Windows попросит права администратора: они нужны, чтобы создать сетевой интерфейс VPN.

Устанавливать ничего не нужно: драйвер WireGuard (wintun) встроен в программу. Дальше приложение обновляется само.

> Если Windows SmartScreen показывает предупреждение, нажмите «Подробнее» → «Выполнить в любом случае». Программа не подписана сертификатом разработчика.

## Быстрый старт

1. **Добавьте сервер.** Нажмите на ссылку `wdtt://` (она откроется в RWDTT), вставьте её через **Ctrl+V** в любом месте окна или нажмите `+`.
2. **Добавьте VK-хеши**, если их нет в ссылке. Откройте профиль сервера → «Хеши» и вставьте код или всю ссылку звонка `vk.ru/call/join/…`. Можно добавить до 4 хешей.
3. **Подключитесь** кнопкой питания.

Перед подключением отключите другие VPN.

## Ссылки

### WDTT Plus

```
wdtt://connect?v=1&host=<адрес>&dtls=<порт>&wg=<порт>&local=<порт>&password=<пароль>&hashes=<хеш1>,<хеш2>[&name=<название>][&max_workers=<N>]
```

- `host` — IPv4 или домен сервера, `dtls` — порт сервера, `local` — локальный порт клиента.
- `hashes` может быть пустым. Тогда после импорта откроется профиль, чтобы добавить свои VK-хеши.
- `max_workers` — предел мощности от владельца сервера. Ползунок «Мощность» не даст его превысить.
- Повторный импорт ссылки с тем же адресом и паролем обновляет профиль, а не создаёт дубль.

### Старые форматы

```
wdtt://<адрес>:<DTLS-порт>:<WG-порт>:<локальный порт>:<пароль>[:<хеш1>,<хеш2>,...][#название]
qwdtt://config?name=<название>&peer=<адрес:порт>&pass=<пароль>&hashes=<хеши>&workers=<N>
```

Ссылку можно вставить вместе с текстом сообщения — приложение само найдёт её.

> Короткие ссылки бота вида `https://<домен>/c/<код>` не поддерживаются: они работают только в Android-приложении WDTT Plus. Попросите у владельца полную ссылку `wdtt://connect?…`.

## Настройки

| Настройка | Что делает |
|---|---|
| **Открывать ссылки wdtt://** | Ссылки `wdtt://` и `qwdtt://` из браузера и мессенджеров открываются в RWDTT. Права администратора для этого не нужны. |
| **Запускать при старте** | Автозапуск вместе с Windows. |
| **Режим обфускации** | Маскировка под аудио- или видеозвонок. |
| **Подключение** | **UDP** (по умолчанию) или **TCP/TLS**, плюс внешний SNI в разделе «Дополнительно». |
| **Исключения из туннеля** | Список сайтов, IP и подсетей, которые идут напрямую. |
| **Проверить обновления** | Ищет новую версию прямо сейчас. |

### Подключение

Работает так же, как «Подключение» в WDTT Plus:

| Режим | Как работает |
|---|---|
| **UDP** — «UDP, при недоступности — TCP/TLS» | Все потоки идут к серверам VK по UDP. На TCP/TLS клиент переходит, только когда рабочих UDP-каналов не осталось совсем; новые проверки UDP после этого откладываются на 5 минут. Отказ отдельного канала остальные не трогает. |
| **TCP/TLS** — «Без внешнего UDP» | UDP до VK не используется: сначала TLS (если VK выдал такой адрес), затем TCP. Для сетей, где режут UDP. Обычно медленнее. |

**Дополнительно → Внешний SNI** — имя сайта из белого списка вашей сети (например, `ya.ru`) для подключений TURN/TLS. Сертификат VK всё равно проверяется по настоящему имени. Пусто — без подмены.

Канал считается рабочим, только когда по нему отвечает ваш сервер. Работающие каналы никогда не обрываются из-за смены режима. Выбранный режим виден в логах: `[ПОДКЛЮЧЕНИЕ] UDP: …`.

### Исключения из туннеля

Вводите по одному на строку:

```
gosuslugi.ru
https://www.sberbank.ru/ru/person
1.2.3.4
192.168.0.0/16
```

- Изменения применяются сразу, даже при активном подключении.
- Адреса сайтов обновляются каждые 2 минуты.
- Поддомены добавляйте отдельно, `www.` добавляется автоматически.
- Исключения работают по IP-адресам. Сайт на общем CDN исключается вместе с соседними сайтами на тех же адресах.
- Если в браузере включён «Безопасный DNS», браузер может получить другие адреса, чем приложение. Тогда добавьте подсеть.
- Поддерживается только IPv4.

## Совместимость с серверами

| Сервер | Режим |
|---|---|
| **WDTT Plus** | Полностью как в Android-приложении WDTT Plus: подключение делает его собственный клиент. |

Каждый компьютер подключается со своим ID устройства. Пароли, выданные владельцем сервера, привязываются к первому устройству: на второй компьютер нужен отдельный пароль. Пароль, который раньше использовался в RWDTT (RWDTT) до версии 1.7.3, принимается как есть.

## Обновления

Приложение проверяет [релизы](https://github.com/makdren/PWDTT-Plus/releases) при запуске и по кнопке «Проверить обновления». По кнопке «Обновить» оно:

1. скачивает новый exe и сверяет его контрольную сумму SHA-256;
2. отключает VPN, заменяет программу и перезапускается.

Если что-то пошло не так, остаётся прежняя версия.

1. Откройте **Настройки** (шестерёнка).
2. Нажмите **Отчёт** — сведения о системе и логи сессии скопируются в буфер обмена.

Перед отправкой просмотрите отчёт: в нём есть имя компьютера и логи текущей сессии.

## Для разработчиков

### Сборка

**Нужно:** Go 1.26+, Node.js 22+, [Wails v2](https://wails.io).

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.14.0
git clone https://github.com/makdren/PWDTT-Plus
cd PWDTT-Plus
scripts/build-engine.sh   # клиент WDTT Plus → assets/wdtt-client.exe
wails build -platform windows/amd64 -ldflags "-X pwdtt/backend.Version=1.7.0"
```

Готовый файл: `build/bin/rwdtt.exe`.

Версия WDTT Plus, из которой собирается клиент, закреплена в [`engine/WDTT_PLUS_REF`](engine/WDTT_PLUS_REF). Чтобы перейти на новую, запишите туда коммит WDTT-Plus и выпустите версию.

### Тесты

```bash
cd core && go test ./... && cd ..
go test ./backend/ ./tests/
cd frontend && npx vitest run
```

### Выпуск версии

```bash
scripts/release.sh 1.7.1 --watch
```

Скрипт проверяет, что версия больше последней, прогоняет тесты, отправляет код и тег `v1.7.1`. GitHub Actions ([release.yml](.github/workflows/release.yml)) собирает `rwdtt-windows-amd64.exe` с контрольной суммой и публикует релиз. С `--watch` скрипт ждёт окончания сборки.

Если загружаете релиз вручную: тег вида `v1.7.1`, exe с `windows` в имени, релиз не черновик и не pre-release.

### Устройство проекта

| Папка | Что внутри |
|---|---|
| `backend/wdtt_engine.go` | Запуск клиента WDTT Plus и разбор его вывода (конфиг, капча, статистика, отказы сервера). |
| `backend/` | WireGuard, маршруты и исключения, профили, ссылки `wdtt://`, обновления. |
| `engine/`, `scripts/build-engine.sh` | Версия и сборка встроенного клиента WDTT Plus. |
| `core/` | Прежнее ядро PWDTT; используется только вне Windows. |
| `frontend/` | Интерфейс (React + Vite). |
| `main_windows.go` | Окно, трей, единственный экземпляр. |
